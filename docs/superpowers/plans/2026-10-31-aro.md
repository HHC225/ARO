# ARO Implementation Plan

> **For agentic workers:** Use the subagent-driven-development workflow for isolated modules and integrated verification.

**Goal:** Deliver and publish the cross-platform inventory, advisory and approved-patching skill described in the design.

**Architecture:** A standard-library Python package bundled inside the skill. Independent collectors and advisory adapters feed a shared state, risk and patch engine.

**Tech Stack:** Python 3.11+, Bash, PowerShell, unittest, optional Syft and Trivy.

**Spec:** `docs/superpowers/specs/2026-10-31-aro-design.md`

## Global Constraints

- English skill instructions, comments and code; English, Korean, Japanese and Chinese READMEs.
- Python 3.11+, standard library only for the core; Linux and Windows launchers.
- No target modification during inventory/check, no source-code upload, explicit approval for patch execution.
- Structured coverage and freshness; never equate a failed check or CGNAT with safety.
- Only scoped file owners edit their modules; the coordinator handles integration and Git operations.

## Review Focus

- Untrusted manifest/advisory strings must not become shell syntax or arguments that change command meaning.
- Docker visibility and Windows metadata can be absent: report coverage instead of success.
- Unresolved versions, distro backports and branch-specific fixes must not produce false certainty.
- Interrupted scans and patches must preserve usable state and force reconciliation.
- Offline cache and upstream partial failures must not yield a clean bill of health.

## Task 1: Inventory

Files: `scripts/aro_core/inventory.py`, inventory tests and fixtures. Interface: `collect_inventory(roots: list[str], options: dict | None = None) -> dict`. Roots are resolved by the CLI; use the design's JSON contract. Tests cover representative lockfiles, redaction, partial collection and stable IDs. Implement native Linux/Windows and Docker collectors, optional Syft, bounded discovery and coverage. Verify tests before handing off.

## Task 2: Advisory adapters

Files: `scripts/aro_core/advisories.py`, advisory tests and fixtures. Interfaces: `build_source_plan(inventory: dict, config: dict | None = None) -> list[dict]`, `query_advisories(inventory: dict, cache_dir: pathlib.Path, options: dict | None = None) -> dict`. Return `advisories`, `sources`, `coverage`, `source_plan`; report source status/freshness. Tests cover exact package matching, pagination, official runtime records, fixed branches, cache failures and withdrawals. Research primary sources and link them in reference documentation.

## Task 3: Skill and distribution docs

Files: `SKILL.md`, `agents/openai.yaml`, references, four root READMEs, repository governance, installation helpers if needed. Run a baseline scenario before writing instructions, then verify a fresh agent can follow the completed skill. Keep instructions concise and installation compatible with common skills clients.

## Task 4: Coordinator engine

Files: common/state/exposure/patching/CLI modules, entrypoint, platform launchers, tests, CI. Tests first for map reconciliation, short risk output, stale/tampered patch plan rejection and post-patch refresh. Implement deterministic state and approval-bound execution. Run full unittest discovery, Linux smoke tests, Windows CI and independent final review, fix material findings, commit and push to the user-authorized repository.
